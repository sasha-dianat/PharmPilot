# Known Gaps and Risks

| Severity | Confidence | Gap/Risk | Evidence paths | Impact | Recommended disposition |
|---|---:|---|---|---|---|
| Critical | High | Patient child routes lack tenant parent checks. | `services/platform/routers/patients.py` allergy/insurance/lab/note routes query child tables by `patient_id` only. | Cross-pharmacy PHI read/write/delete possible if UUID known. | Fix before feature work; add same-tenant/cross-tenant tests. |
| Critical | High | Rx queue WebSocket is unauthenticated and trusts path `pharmacy_id`. | `services/platform/routers/prescriptions.py` `rx_queue_websocket`; `frontend/workstation/src/stores/rxQueue.ts`. | Queue PHI and workflow state can be streamed cross-tenant. | Add authenticated WebSocket ticket flow and pharmacy match enforcement. |
| Critical | High | Biometric routes lack normal auth/tenant scoping. | `services/platform/routers/biometric.py` `identify`, `enroll`, `stream`, `_preload_patient_profile`. | Biometric data and patient preload can leak or be manipulated. | Require staff or edge-node credentials; scope preload by pharmacy. |
| Critical | High | Audio transcript routes lack auth and tenant checks. | `services/platform/routers/audio.py` `transcribe`, `get_patient_transcripts`, `approve_enrichment_action`. | PHI transcript disclosure and unauthorized profile enrichment. | Require authenticated reviewer; reject client-supplied pharmacist identity. |
| Critical | High | Security event ingest/stream are unauthenticated. | `services/platform/routers/security_events.py` `behavior-detection`, `stream/{pharmacy_id}`. | False alerts, sensitive surveillance exposure, cross-tenant event visibility. | Add machine credential for edge ingest and authenticated stream access. |
| High | High | Refresh-token sessions expire at access-token duration. | `services/platform/auth.py` `authenticate_staff`; `services/platform/routers/auth.py` `refresh_token`. | Refresh flow may fail unexpectedly and does not match `REFRESH_TOKEN_EXPIRE_DAYS`. | Store refresh expiry separately or set session expiry to refresh duration. |
